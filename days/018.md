# Install and Configure DB Server

We need to setup a database server on `Nautilus DB Server` in Stratos Datacenter. Please perform the below given steps on DB Server:

a. Install/Configure MariaDB server.
b. Create a database named `kodekloud_db9`.
c. Create a user called `kodekloud_cap` and set its password to `Rc5C9EyvbU`.
d. Grant full permissions to user `kodekloud_cap` on database `kodekloud_db9`.



## Steps

### Configure App Server

1. Install MariaDB

First, log into the DB server and install the MariaDB server package.

```sh
Bash
sudo yum install -y mariadb-server
```

2. Start and Enable the Service

Start the MariaDB service and ensure it is set to launch automatically on system boot.

```sh
Bash
sudo systemctl start mariadb
sudo systemctl enable mariadb

```

3. Create Database, User, and Grant Permissions
You can perform the database operations by logging into the MariaDB shell. By default, the root user has no password on a fresh installation.

Enter the MariaDB shell:

```sh
Bash
sudo mysql -u root
```

Run the following SQL commands:

```sh
SQL
-- Create the database
CREATE DATABASE kodekloud_db9;

-- Create the user with the specified password
CREATE USER 'kodekloud_cap'@'localhost' IDENTIFIED BY 'Rc5C9EyvbU';

-- Grant full permissions on the new database to the new user
GRANT ALL PRIVILEGES ON kodekloud_db9.* TO 'kodekloud_cap'@'localhost';

-- Apply the changes
FLUSH PRIVILEGES;

-- Exit the shell
EXIT;
```

### Verify Result

To ensure everything was created correctly, try logging in with the new user and checking for the database:

```sh
Bash
mysql -u kodekloud_cap -pRc5C9EyvbU -e "SHOW DATABASES;"
```

If you see kodekloud_db9 in the output list, the configuration is successful.
